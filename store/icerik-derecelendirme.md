# IARC içerik derecelendirme anketi

Reyon bir mağaza rafı alıştırmasıdır: ürün yerleştirme, plana uygunluk denetimi,
satış düzeni ve stok kararı. Şiddet, korku, cinsellik, kumar, madde kullanımı,
kullanıcı etkileşimi ve konum paylaşımı içermez.

| Soru başlığı | Cevap |
| --- | --- |
| Şiddet | Yok |
| Korku | Yok |
| Cinsellik / müstehcenlik | Yok |
| Kaba dil | Yok |
| Kumar (gerçek ya da simüle) | Yok |
| Madde kullanımı | Yok |
| Kullanıcılar arası etkileşim | Yok (ağ yok) |
| Konum paylaşımı | Yok |
| Kişisel bilgi paylaşımı | Yok |
| Dijital satın alma | Yok |
| Reklam | Yok |

İçerikte dikkat çeken tek nokta, ürün adlarının gündelik market ürünleri olmasıdır
(su, süt, peynir, deterjan, şampuan…); alkol ve tütün yoktur.

Beklenen sonuç: PEGI 3 / ESRB Everyone / USK 0.
